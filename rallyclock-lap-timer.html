Lap timer

For test days rather than events: one car, lap after lap, with every lap compared to the best.

Open it

Open Setup, and under What this control is, choose Lap Timer. The timing screen becomes the lap timer, with its own help page.

Timing a run

  1. Tap Add car and put in the car number. It goes on every row of the session, so logs from several timers on several cars can be merged and still say whose laps are whose.
  2. Press START as the car crosses the start/finish line for the first time, not while it warms up. That's lap 0.
  3. Press CAPTURE each time it crosses the line, the last lap too. Each press ends a lap, and the next lap is timed from that press.
  4. Press STOP once it's done: on the cool-down, or as it comes into the pits. STOP ends the run but isn't a lap, so the short stretch to the pits never counts as the best one. The button goes back to START for the next run.

Reading the screen

  • The big number is the lap running now.
  • Underneath: which lap it is, and the total since START.
  • Once a lap is done, the colored line says how far this lap is off the best one. Green with a minus: still quicker than the best. Red with a plus: slower.

The list

  • Each row is a lap: its time, then which lap, the total, and how far off the best it was. The best lap says Best.
  • A car number typed wrong can be fixed mid-session: tap the car and change it, and every row of the session changes with it.

If you press by mistake

Tap Void last. The row stays crossed out, and that lap joins the next one: it's timed from the last press that still stands. Voiding START takes the timing of its run with it, because every lap was timed from it.
