Setting the clock

A stage time is one device's finish minus another's start, so what matters most is that the devices agree with each other. Rally Clock keeps its own clock for this, and never changes the device's.

Ways to set it

Tap the clock icon at the top right. In order of preference:

  1. Set clock asks an internet time server, while you have signal. It's pool.ntp.org, unless the event's setup or Time server in Setup names another.
  2. Copy from another device takes the time from the stage's main clock (below).
  3. Satellite time, on Android only, with a clear view of the sky. iPhones, iPads, Macs and Windows give apps only the device's own clock, so set those from the internet or copy a clock.
  4. Set at top of minute, by hand, against a time you trust.

Every change is written into the log, so scoring can allow for it.

One main clock for the stage

On the device that will be the main clock:

  1. Set its clock as well as you can first: Set clock while there's signal, or on Android, satellite time.
  2. On the Clock screen, turn on This is the main clock.

On every other device:

  1. On the Clock screen, under Copy from another device, the main clock appears by its control name, usually within a couple of seconds.
  2. Tap Copy. If cars have already been timed, it asks first, because changing the clock mid-control puts earlier and later times on slightly different clocks.
  3. The result says how far the clock moved and how closely it matched, for example "Matched SS4 · Stop: -0.119 s (±5 ms)".

Do this before the devices leave for their controls, with all of them on the same Wi-Fi or hotspot, then turn the main clock off. The clocks keep time on their own all day, with no signal.

The line at the top

  • Tick: the clock has been set and is good.
  • Grey question mark: nobody has checked the clock today. Ask the organizer before the first car if you can.
  • Red warning: the device moved its own clock. Your times are still correct, so carry on and mention it to the organizer. If it says your times may be out, set the clock again.

After the device restarts, the line says "Clock may have moved — check it" until you set the clock again.

Checking without changing

On Android, outdoors, tap the line above the clock, then Check, do not change under Satellite time. It should agree with internet time to a fraction of a second, even on a phone whose own clock is wrong. Indoors it says it can't see the satellites, which is expected.
